신청 취소

기획 메모: 계약금 결제 전

1세금계산서 발행 신청 섹션 위치
  • 참가 취소 안내 아래, 결제하기 바로 위에 붙음.
  • 1인 작가, 기업 참가자 모두 같은 섹션을 봄.
  • 결제할 금액이 남아 있지 않은 신청서(완납, 참가 취소)에는 노출하지 않음.
  • 현금영수증(소득공제, 지출증빙)은 이 섹션에서 받지 않음. 증빙 발행 폼에서 받음.
2신청 체크
  • 처음에는 체크박스만 보이고 입력 항목은 숨김.
  • 체크하면 입력 항목이 펼쳐지고, 해제하면 접히며 입력하던 값은 저장하지 않음.
3결제하기 버튼 활성 조건
  • 신청하지 않음: 지금처럼 제3자 제공 동의만으로 활성화됨.
  • 신청함: 제3자 제공 동의, 필수 항목 8개 입력, 정보 수집 및 이용 동의가 모두 채워져야 활성화됨.
  • 형식이 틀린 칸은 칸 아래 빨간 글씨로 안내함.
4저장
  • 결제하기를 누르는 시점에 신청서 단위로 저장됨.
  • 결제에 실패하거나 결제창을 닫아도 저장값은 남아, 다시 결제할 때 그대로 채워짐.
  • 저장된 신청은 마이페이지 증빙 발행 신청 내역과 어드민 증빙 발행 확인에 신청 경로 확정 화면으로 들어감.
확인이 필요한 것
  • 완납으로 입금(사무국 계좌) 선택 시: 결제하기 버튼이 없어 저장 시점이 없음. 이 경우 섹션을 숨기고 증빙 발행 폼으로 안내할지, 별도 저장 버튼을 둘지 정해야 함.
  • 사업자등록증 사본: 사업자 등록번호를 국세청 조회로 확인한다면 선택으로 바꿀 수 있음.
  • 기업 참가자: 체크된 상태를 기본값으로 보여줄지 정해야 함.

신청 취소

기획 메모: 잔금 결제 화면

5계약금 때 신청한 경우
  • 저장된 정보를 라벨, 값 목록으로 보여주고 정보 수정하기 버튼을 둠.
  • 계약금 때 저장한 정보는 잔금 세금계산서에도 그대로 쓰임. 다시 입력하지 않음.
  • 정보 수정하기를 누르면 입력 항목이 저장값으로 채워진 채 펼쳐지고, 결제하기를 누를 때 다시 저장됨.
6계약금 때 신청하지 않은 경우
  • 계약금 화면과 같은 체크박스를 보여줌. 여기서 신청하면 잔금분부터 발행됨.
7사무국이 발행을 마친 경우
  • 어드민에서 발행 완료 처리하면 정보 수정하기 버튼을 숨기고, 세금계산서가 발행되어 수정할 수 없다는 문구를 보여줌.
확인이 필요한 것
  • 계약금을 이미 결제한 V.23 참가자가 잔금 때 신청하면, 계약금분도 함께 발행할지(소급), 잔금분만 발행할지 정해야 함.
  • 발행 시점: 섹션 문구가 페어 종료 후 30일 이내 일괄 발행 기준임. 입금일 기준 발행이 필요하면 희망 발행 일자 칸을 다시 넣어야 함.
  • 입금 내역 아래 증빙 발행 안내(OCH-1577 문구, 증빙발행정보는 추후 접수 예정이며…)는 이 섹션이 생기면 맞지 않아 함께 고쳐야 함.
